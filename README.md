Title-JUST A CALCULATOR

Hey there! This is a clean, simple, and responsive web calculator I built for Hack Club Macondo. I wanted to make something straightforward that works perfectly on both phones and computers.

 Live Link
Check it out live here: https://magical-wisp-764bd1.netlify.app/



 Features-
The Basics: Handles addition, subtraction, multiplication, and division.
Responsive Design: Buttons scale nicely whether you are on mobile or desktop.
Clean UI: Simple layout with smooth hover effects on the buttons.


 Built With
HTML5 for the structure.
CSS3 for the styling and grid layout.
JavaScript for the actual math logic and button clicks.


 What I Learned
Building this helped me practice using CSS Grid to align buttons neatly. I also learned how to handle user inputs in JavaScript and prevent weird bugs, like clicking the decimal point multiple times in a single number.
